# Proyecto3_UCI_Plantas
El objetivo de este proyecto es diseñar y desarrollar un prototipo de un producto interactivo que integre componentes de hardware y software, aplicando principios de modelación orientada a objetos, integración hardware/software y experiencia de usuario, con el fin de resolver una necesidad específica mediante una solución funcional y estética
